## Terminal Architecture

### Workspace Model
- Up to 8 workspaces (tabs)
- Each workspace has 1-4 panes
- 8 layout presets (single, split-h, split-v, main-side, side-main, top-split, split-top, quad)
- State persisted to Tauri store

### Pane Modes
- `local` — Local PTY session
- `ssh` — SSH connection (via bastion if configured)
- `claude` — Claude CLI session

### Terminal Modes (AI Behavior)
- `strict` — Maximum caution, confirmation-heavy, stepwise changes
- `balanced` — Practical daily mode, executes directly, asks when risk is real
- `builder` — High-autonomy for power users, faster execution
- `audit` — Read-only diagnosis, no modifications

### Model Selection
- `sonnet` — Sonnet 4.6 (default)
- `opus` — Opus 4.6
- `haiku` — Haiku 4.5

### Event Flow
```
User Input → TerminalEmbed → ptyWrite() → Rust PTY → Shell
Shell Output → Rust PTY → Tauri Event → onPtyOutput() → xterm.js
```

### Claude Mode Flow
```
User Input → ClaudeInputBar → claudeWrite() → Rust Claude Session → Claude CLI
Claude Output → stream-json → Tauri Event → claudeOutputParser → ClaudeConversation
```
